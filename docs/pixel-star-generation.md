# Pixel star favicon

Created with the built-in ImageGen tool. Source: `src/images/pixel-star.png`.
Public PNG and ICO exports use nearest-neighbor resizing. The browser favicon,
Apple touch icon, install manifest, Open Graph image, and Twitter image all use
the pixel star.

Final generation prompt:

Use case: logo-brand. Asset type: pixel-art favicon and shared-link icon for a dark personal portfolio with a space theme. Create one simple four-point pale lavender star centered on a solid dark charcoal #101116 square background. True very coarse 16x16 pixel-art design enlarged with nearest-neighbor, crisp large square pixels and stepped edges. Symmetrical diamond-like sparkle with long vertical and horizontal points and a compact center. Use only two or three flat colors: dark charcoal background, pale lavender #e0e5ff star, optionally one slightly brighter pixel highlight. Strong silhouette clearly recognizable at 16 and 32 pixels. Star occupies about 75 percent of square, even margin. No glow, no blur, no gradients, no texture, no anti-aliasing, no face, no text, no other objects, no mockup. Single square icon.
